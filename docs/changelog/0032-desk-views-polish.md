## What changed

- **Shared card (`ScheduleCard`, new molecule)**: every appointment and booking card on a board or a grid is now one component - a 3 px lifecycle status stripe down the left, the time, an assignee chip (groomer name on a dot in the groomer's hue), pet + breed, customer, package · size and add-on / minutes chips, and alert badges (Vaccine, Unpaid, Check) that appear **only when they apply** instead of a row of greyed-out icons. Each card has exactly one 44 px "more" menu. The legacy R-G20 label ("Owner Last, PET; Breed; Package Size") stays as the card's accessible name and tooltip, so screen readers and long-time staff still get the old string. A `compact` variant (day grid) shows at most one alert chip, or "N alerts" when several apply. `GroomAppointmentCard` is deleted (D-231).
- **Board (`AppointmentBoard`)**: one organism for the Grooming & Spa board (F-14) and the grooming board (F-31); `GroomStatusBoard` is deleted. Each column head is a status dot + label + count + a collapse button; empty columns shrink to a compact "Nothing here" line; the column strip scrolls sideways with scroll-snap, a visible scrollbar and an edge fade so it is obvious there is more to the right; KPI tiles sit on one row from ~1100 px. Cards keep drag-and-drop, and every move is also a menu entry, so nothing is drag-only (D-195, D-234).
- **Timeline (`RoomTimeline`, F-13)**: the grid reads as a calendar again. Alternating day columns are a tint (`--color-grid-alt` #F6F7F9, head #EEF1F4) instead of the old #CDD2D8 block; weekends get their own `--color-grid-weekend` and are marked in the header; group rows are grey only in the label cell with a hairline running across; the day header and the room column are sticky; today is a thin dashed line plus a small "Today" pill rather than a filled column; bars are 6 px-radius with a dark left edge (`--color-bar-edge`) and a 13 px "Pet · Customer" label; a bar under 76 px (one-night stays) shows a "…" chip and keeps the full label in its `aria-label`; the popover opens on click, Enter **or** hover and takes focus when opened from the keyboard. Room cells show the room code plus a 2-letter type badge, and the group count pill stays in view while scrolling (D-232).
- **Day grid (`GroomDayGrid`, F-30)**: groomer heads are white cards with an initials disc in the groomer's hue and a 3 px coloured top border, instead of a saturated full-colour bar. Working hours are an 8 % tint of that hue, off hours a low-contrast hatch, half-hours a faint line. Overlapping appointments split the column into side-by-side lanes rather than stacking on top of each other; the over-capacity warning is a chip beside a neutral hour label; the now line is a hairline with a time chip and only renders when the shown day is today. A legend row (Requested / Confirmed / In progress / Done + hidden-column chips) sits above the grid and a helper line below it (D-233).
- **Table and agenda (F-10, F-32)**: a new `num` cell tone (tabular numerals in body colour) replaces the Figma purple on times, dates, counts, phone numbers and money, so only real links read as links; the purple table head stays (D-216). Group rows became section rows: uppercase label + a count `Badge` + caret, a hairline above each section, a 32 px focusable button with a visible focus ring. The agenda's status column is the status badge plus chips that appear only when they apply (D-235).
- **Tokens**: new `groomerHues` scale (`--groomer-1..6`, light and dark) in `src/design/tokens.ts`; `color-grid-alt` / `color-grid-alt-head` softened; new `color-grid-weekend` and `color-bar-edge`; regenerated `src/styles/tokens.css`. A `.tnum` utility in `global.css`. `Avatar`'s `initials()` is now exported for the surfaces that draw their own tinted disc.
- **Seed**: the three Encino groomers' `employees.color` values are remapped from the old saturated green / yellow / cyan (#039B00, #F4D06F, #7FDBDA) onto `groomerHues.light[0..2]` (#6E93C4, #6FA97E, #C39A57), so the day-grid heads, discs and column tints use the palette rather than fighting it (D-233). `SEED_VERSION` 4 -> 5 so existing localStorage databases reseed. Nothing else in the seed changed.
- **Strings, specs and actions**: 26 new `{ en, es }` keys in `frontdesk-grooming-people` and 15 in `frontdesk-reservations` (card menu, column options, legend, board hint, popover labels) - no hard-coded English in the JSX (D-206). The six specs gained their `actions` manifests (F-10 eight, F-13 ten, F-14 nine, F-30 eleven, F-31 six, F-32 six), rewritten layout / logic / states lines, `components` naming `ScheduleCard` and `AppointmentBoard`, and `checkedAt` raised to the full 360 / 390 / 768 / 1280 / 1920 / 2560 / 3840 matrix (D-194, D-197).
