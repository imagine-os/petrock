# F-10 · Hotel & Daycare reservations (table)

## Purpose

The reservations table of the Figma v2 design with its 18 columns, grouped into collapsible Arriving / Departing / Staying / Daycare / Checked out sections for the selected day, plus an "All upcoming" mode. Filters (status, hotel vs daycare, room type, cancelled toggle) and search sit in the header bar; the Table / Timeline / Board switch implements D-008 (Hotel & Daycare get Table + Timeline, Spa gets Board).

## Sections (layout order)

1. PageHeader - ViewSwitch (Table / Timeline / Board), `ReservationDayNav`, "+ Hotel reservation" (R-I08)
2. Filter bar - search, status, kind, room type, "Cancelled / no show" toggle
3. Mode tabs - By day (bucket groups) / All upcoming
4. Group sections - collapsible with counts; each a dense `DataTable` with the 18 columns (`lib/columns.tsx`) and Open / Edit actions
5. Daycare drawer - summary of a daycare row (daycare check-in / pricing belong to F-40s)

## Data

| Table | Read / write | Notes |
| --- | --- | --- |
| `bookings`, `booking_pets`, `daycare_bookings` | read | joined by `useReservationRows()` |
| `customers`, `pets`, `rooms`, `room_types` | read | names, breeds, room codes |
| `vaccine_records`, `vaccine_types` | read | vaccine flag next to the status |

## Rules

- `R-I05` - Arriving / Departing / Staying / Checked out groups (plus Daycare)
- `R-I02`, `R-I01` - design chips Future / Checking In / Checked Out map to the lifecycle
- `R-D14`, `R-H08` - Balance = Total charge - Deposits
- `R-I08` - page-level "+ Hotel reservation" entry point
- `R-K01` - rows scoped to the current location

## Logic

- The 18 columns: ID, Status, Customer, Hotel room, Date in, Time in, Date out, Time out, Nbr days, Pet(s), Breed, Pet count, Mobile, Home, Total charge, Deposits, Balance, Booking notes.
- Nbr days = nights (hotel) or 1 (daycare); Home = customer alt phone.
- Cancelled / no-show rows hidden unless toggled.
