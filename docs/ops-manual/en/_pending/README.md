# Pending manual drafts

Module agents drop one file here per staff-facing module (`<module>.md`): the chapter material for what they built (which screen, which steps, which rules), written in the chapter conventions of `docs/ops-manual/README.md`. The integrator merges drafts into numbered chapters under `docs/ops-manual/en/` and deletes them. Drafts show on `/#/manual/pending` so nothing is lost meanwhile.
